# Mapping Data for Exploratory Analysis

Running this file opens a temporarily hosted map in browser with each location featured in the data as a point. The file includes 3 separate maps (trees, CATS/Traffic/Law 84, and air quality sensors).

# Data Requirements - Put these files in the empty "data" folder

**2015_Street_Tree_Census.csv**: NYC Open Data: 2015 Tree Census - Tree Data

**Law_84_Disclosure.csv**: NYC Open Data: Energy and Water Data Disclosure for Local Law 84

**NYCOpenAQ.csv**: Open AQ data from the drive

**purple_air_monthlypm25.csv**: Purple air data from the drive

**epa_all_station_monthly_means.csv**: EPA data from the drive

**traffic_counts_with_coordinates.csv**: Cleaned traffic data from the drive

**CATS.csv**: Taxlot data from the drive (make sure to use the Staten Island version)

**Forestry_Tree_Points.csv**: NYC Open Data: Forestry Tree Points

**Library requirements found in requirements.txt**
